## Deviations

- ECON-3: no dedicated admission goroutine. Admission is a "pump" run under the
  scheduler mutex by enqueue / release / resume / a `context.AfterFunc` on the
  Execute ctx (drops queued tasks on cancel). Same semantics (round-robin, G and
  per-host caps, saturated hosts hold no slot) without a goroutine lifecycle to
  leak. Host key is host:port (the egress gate / limiter key), not the
  scheme-qualified origin. Untracked host cap = limiter ceiling; no limiter = G.
  `ExecutorConfig.HostTaskCap` injects the cap (tests). RES-10 hook: G halves
  while `network.IsLowOnMemory()`.
- ECON-3 item fairness: parked items live in a bounded (1024) deferred list,
  re-sent from the feed loop / drain loop once the host backlog drops
  (forced when nothing is in flight); still-parked items at shutdown count unacked.

- CallStats consumption: "inconclusive_throttled" = call completed, CallStats.Throttled>0,
  no event with IsFinding(). Counted in ModuleSkips + ModuleStatsSnapshot.Inconclusive;
  runner notes limit `throttled` (not partial). ExecutionReport.ModuleSkips is
  cumulative per executor (executors are single-Execute). Executor counts
  tech_filter, cannot_process, ip_type, param_already_found, timeout,
  inconclusive_throttled (header_gated added with ECON-1; method_policy and
  quarantined are Track A/C counters).
- MISS-32: added `feedback_dropped` reason and `throttled` limit to outcome.go
  (contract codes; integrator dedups with Track C).
- MISS-19: `runActiveWithTimeout` keeps its (events, completed) signature; new
  `runActiveCall`/`runPassiveCall` return `callOutcome{events, completed, err}`
  and the per-host loops use them. Retry count lives in `HostClaims` (shared via
  NEW-8). Sweep covered the 38 passive modules whose host-keyed `IsSeen` ran
  before matching, plus jwt_weak_secret (claim after a token is found). Active
  per-host modules keep their own host DiskSet before probing (probe-once is
  their contract), so the executor retry re-runs them only where the module
  itself does not dedup — not swept (would need un-see on failure per module).
- MISS-12: migrated modules that build through insertion points: lfi_path_traversal,
  lfi_generic (rule.withPreEncoded), crlf_injection, response_header_injection
  (replaces its hand-rolled injectRawPayload), smtp_header_injection,
  input_behavior_probe (paramFuzzChars table is pre-encoded). cache_deception,
  nextjs_middleware_bypass and forbidden_bypass build paths directly (not via
  insertion points) so they are untouched. Added `httpmsg.BuildPayload(ip, p, preEncoded)`
  convenience next to `BuildPreEncoded`. Header pre-encoded = raw value with only
  control bytes escaped.
- MISS-17: new active module `xss-light-body-params` (registry count 216→217;
  README/HACKING/CLAUDE/modules-reference/overview counts bumped, modules-reference
  row added). Prefilter is strict: the body value (>=3 chars) must already appear
  in the stored response. Non-GET findings are Suspect/Tentative with
  `Metadata.claimed_severity`. Stored XSS candidate pages: submit URL, Referer
  (same origin or in scope via ScanContext.IsScanTarget), collection URL (path
  minus last segment); cap 3.
- MISS-20: late harvester downgrades when CallStats.Refused OR Abandoned > 0
  (which counter Track A bumps for post-abandon refusals is not fixed by the
  contract). Late events carry `Metadata.late_result=true`. Harvester waits
  min(timeout, 30s); not tied to the item tracker (the item acks on time).
  `runActiveWithTimeout` (tests) ignores late results; the dispatch sites use
  `runActiveCall` + `deliverCall`.
- ECON-6: generic `ScanContext.EndpointMemo(name, rec, ttl, compute func() (any, cache bool))`
  plus `ScanContext.TimingThreshold` (key `timing-baseline-v1`, int64 ns, -1 =
  blocked, TTL 2m) measured from the record's UNMODIFIED request with the
  requester-measured elapsed (Execute's duration). command_injection_timing now
  also skips blocked baselines (it did not before). Boolean-blind memoises the
  raw unmodified response (TTL 2m) and builds each point's signature with its own
  base value; drift re-check unchanged; plain pairs stop after 3 consecutive
  blocked pairs (WAF variants + HPP still run).
- ECON-14: CrackHMAC keeps the RS/ES/PS alg-confusion variants (existing tests
  and `kit jwt-crack` rely on them) but skips any variant whose hash size differs
  from the signature length, so a genuine RSA/PSS token costs zero HMACs (an ES*
  token costs one same-size variant). jwt_weak_secret memoises the crack verdict
  per sha256(token) via ScanContext.HostMemo and files one finding per token per
  scan (DiskSet key `tok:<sha256>`). BodyOnlyPassive adopted by
  cloud_storage_url_harvest, insecure_token_storage, postmessage_handler_detect,
  dom_xss_detect; NOT secret_detect (it also scans headers and the request).
  Body key = sha256(media type + body); LRU lives in HostClaims (phase-shared).
  HttpResponse.HTMLDocument() adopted by anomaly_ranking (only for declared
  HTML), subresource_integrity_detect, mixed_content_detect; the
  tokenizer-based modules (reverse_tabnabbing, password_autocomplete,
  ssr_hydration_xss) were left on their streaming tokenizers.
- RES-7: all 37 metadata violators moved to Severity Suspect (none waived at
  metadata level); finding literals with Tentative above Suspect downgraded the
  same way (aem_rce, aem_ssrf, backup_file_discovery, client_prototype_pollution,
  command_injection_timing, graphql_scan authz/dos, proxy_header_trust,
  sensitive_file_discovery, upgrade_routing_ssrf, aspnet_viewstate_detect,
  csrf_detect, server_action_*). idor: High/Firm only when credentialed AND user
  fields differ, else Suspect/Tentative. nosqli_operator_injection: auth bypass
  re-confirmed by confirmAuthBypass is High/Firm; every other path
  Suspect/Tentative. Waivers (`modules.TentativeSeverityWaivers`): the xss-light
  family (reflection-only Low/Tentative tier rests on a proven HTTP breakout).
  jwt_weak_secret's Low/Tentative is an Observation (not a finding) — left.
  Runtime clamp `clampTentativeSeverity` in emitResult (findings only).
  Docs: modules-reference severities updated, total 335→336 (MISS-17 module).
- ECON-1: `infra.ClassifyHeader` lives in a new infra/header_class.go (same
  package as filter.go). Gate = `modkit.GateHeaderPoint` (executor per-IP stage)
  and `modkit.FilterPointsFor` (the five whole-request modules). Header-only
  modules (types ⊆ HeaderTypes) get every testable class; `HeaderClassAware`
  overrides. Claims (`modkit.HeaderClaims`, phase-shared via SharePhaseState)
  are released when the executor call did not complete; claims taken inside
  FilterPointsFor are not released (module-internal loops). Skips counted as
  `header_gated` (executor and via ScanContext.OnHeaderGated).
  `TestFlagsGeneratedIsCurrent` (pkg/cli) fails until the integrator
  regenerates flags.generated.md for `--header-fuzz` (not touched per rules).
