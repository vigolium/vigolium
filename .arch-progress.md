## Deviations

- SAFE-10: fastdialer classifies "connection refused" as ErrKindNetworkPermanent, so the base retry rule (CheckRecoverableErrors) never retried a refused dial before or after. Kept that; the "not written → retry any method" branch is pinned by a decision-table unit test (TestRetry_SafeToRetryDecision) instead of a refuse-first server. RetryTimeouts set on preflight + heuristics root fetch.
- SAFE-2: Services.HopScope is a plain func field (Services is copied by value in the probe phase, so no atomic); runner builds the scope matcher before NewRequester so it is set before any traffic. The redirect policy reads it per hop.

- SAFE-4: implemented for `vigolium scan`/`run` with -i (deriveFileInputScope before --dry-run; plan.scope gains scope_targets/input_hosts). NOT wired for REST file scans or `ingest --scan-on-receive` (different input plumbing; left for follow-up). admission.go/scan_admission.go unchanged: ScopeTargets are only set when there are no -t seeds, so seed admission never sees them. Target-list inputs (-I urls, burpscope) and OpenAPI with explicit --spec-url scope to every census host. OpenAPI without -t now uses servers[0] as base URL unless --spec-url or --scope-origin all.

- SAFE-8: nuclei templates are not filtered per HTTP method (no per-request method filter in the template API); tag exclusion is the enforcement. Executor gate is in executor_worker (before runActiveStage) rather than computeEligibility (which modules with custom CanProcess bypass), counted on the Executor.

- SAFE-3: InstallCredentialRouter signature is (headers, allow, methodAllowed, patterns) — the method filter and Fetch patterns are explicit parameters. Auto-attached targets (iframes/workers in other sessions) are not routed (their requests carry no extra headers anyway since setExtraHTTPHeaders is no longer used). Crawler withdraw path is now a router policy update (allow returns false once withdrawn).

- SAFE-11: no `--resolvers` CLI flag exists; types.Options.Resolvers added (explicit list wins) but not exposed as a flag. Offline is applied per-run by the runner (applyOffline) and the update check reads the root --offline flag only (settings key not consulted there).

- SAFE-12: report extra-redaction names are the operator -H names only (live-session header names are not known at CLI report time; Authorization/Cookie/*-token/*-key are in the built-in table anyway). Runner notifier gets -H names likewise. SARIF test TestSARIFWebRequestAndResponseParsed now expects redacted Set-Cookie values.

- SAFE-14: scope check is enforced through a WithHostFilter requester view installed by jsext.NewEngine (covers plain, session and batch extension HTTP without changing every call signature) instead of a check inside doRawRequest. sandbox_dir empty = cwd changed existing tests that relied on "anywhere" (they now pass SandboxDir).

- ECON-9: WaitStable settle cap 3s (counted, browser.StableCapHits); resource blocking (fonts/media/third-party images) via the shared Fetch interceptor (config BlockResources default true; browser.ResourcesBlocked); re-spider host parallelism default 2. The INITIAL spidering loop was not parallelised: it shares many per-phase accumulators (capture receipts, harvested sessions, SSO hosts, budget counters) with no locking; converting it safely is a larger refactor, left for follow-up.

- MISS-28a: states with fewer than 30 elements get StructID 0 and never fold (small DOMs differ mostly in text, which SimHash ignores — a wizard step must not fold into the previous one). MISS-28d uses SameStructure (exact or structural clone) rather than exact-hash equality so a clone-folded target still verifies.

- MISS-29: (a) popups get up to 2s to load before CloseOtherWindows (their traffic is captured browser-wide) and in-scope popup URLs land in crawler Stats.PopupURLs — the crawler has no mid-crawl frontier-seeding API, so they are not enqueued as seeds; (b) seenHashes provisional on failed/unavailable bodies and upgradeable, Capture.BodiesFailed → CaptureReceipt.bodies_failed; the bounded body-fetch worker pool was NOT done (the inline fetch shares the capture's per-request state machine; moving it needs a redesign); (c) DOM-XSS prefilter at the drain point NOT done.
